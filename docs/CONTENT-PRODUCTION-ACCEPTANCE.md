# 验收清单

**版本：V1.0**
**关联文档：CONTENT-PRODUCTION-DESIGN.md**

## A. 人工控制

- [ ] 选择一个帖子后只上传该帖子附件
- [ ] 上传按钮不自动点击发送
- [ ] 可以人工填写提示词
- [ ] 可以人工发送 1
- [ ] 手动下载前必须已有文案
- [ ] 手动打包不会产生缺TXT半成品
- [ ] 页面状态浮层正确显示当前阶段

## B. 选材后自动

- [ ] 单个帖子完整生产（上传→计划→确认→出图→文案→下载→打包→归档）
- [ ] 多个帖子严格串行
- [ ] 父合集正确拆帖
- [ ] 当前帖子未结束前不上传下一帖
- [ ] 计划后只发送一次 1
- [ ] 图片完成后自动请求文案
- [ ] 文案完成后自动保存
- [ ] 图片与TXT统一打包
- [ ] 成功后才增加使用次数
- [ ] 失败素材留在原位置
- [ ] 处理完用户选择的队列后自动停止

## C. 状态检测

- [ ] 附件卡片全部就绪后才发送
- [ ] 正确识别GPT仍在生成（停止图标）
- [ ] 正确识别计划稳定（文本连续N秒不变）
- [ ] 正确解析计划页数（P1…Pn / "共X页" / "先生成前10张"）
- [ ] 正确区分总计划12页与本批10页
- [ ] 正确统计折叠文件组中的图片
- [ ] 正确识别文案完成（长度达标+稳定）
- [ ] 正确识别低图数（1-3张+已停止+稳定）
- [ ] 正确识别Python或脚本降级
- [ ] 不误用旧回复和旧素材
- [ ] 发送按钮状态作为辅助信号而非唯一判断

## D. 检查点恢复

- [ ] 上传后重启不重复上传
- [ ] 计划后重启不重复发送提示词
- [ ] 已发 1 后重启不重复发送
- [ ] 图片生成中恢复不刷新任务
- [ ] 文案完成后恢复可继续打包
- [ ] 断网恢复后从真实页面状态继续
- [ ] 检查点文件包含全部必要字段
- [ ] 恢复时对比本地记录与页面真实状态

## E. 限额处理

- [ ] 显式限额能暂停当前账号
- [ ] 1-3张图能触发低图数判定
- [ ] 记录真实生图开始时间（image_generation_detected_at）
- [ ] 正确计算下次探测时间（开始时间+3小时）
- [ ] 到点后只探测一次
- [ ] 一个账号触顶不影响其他账号
- [ ] 不在限额期反复上传新素材
- [ ] 恢复后可发送重新生成请求
- [ ] 恢复后仍只有1-3张时转人工

## F. 多账号

- [ ] 每个账号只有一个活动任务
- [ ] 账号之间不串素材
- [ ] 账号之间不串提示词
- [ ] 账号之间不串额度时间
- [ ] 切换查看窗口不改变任务绑定
- [ ] 共享素材占用锁有效
- [ ] 当前账号完成后才领取下一帖
- [ ] 空闲账号优先调度

## G. 单账号多对话巡检

- [ ] 能识别已有出图计划的对话
- [ ] 能识别已有完整图片的对话
- [ ] 能识别已有完整文案的对话
- [ ] 能识别只有1-3张图的对话
- [ ] 能识别空白或无效对话
- [ ] 成品正确归属对应素材
- [ ] 下载完成后才能上传下一条
- [ ] 无法识别的对话不自动操作
- [ ] 左侧虚拟滚动不会漏掉会话

## H. 成品与归档

- [ ] 图片均可解码（非0字节）
- [ ] 图片数量和本批预期一致
- [ ] 图片比例正确（1086×1448或当前模板尺寸）
- [ ] 成品图哈希不等于源素材图
- [ ] TXT存在且非空
- [ ] 出图计划.json 存在
- [ ] GPT作品记录.json 存在
- [ ] 成品路径真实存在
- [ ] 文件名无冲突（P1.png, P2.png... 无重名）
- [ ] 素材使用次数只增加一次
- [ ] 当前任务ID与成品记录一致
- [ ] 没有混入上一条任务文件
- [ ] 压缩或移动失败时不删除原文件
- [ ] 不产生重复成品

## I. 工作流编辑器

- [ ] 模块分类正确（触发/素材/会话/上传/等待/检测/控制/输出）
- [ ] 每个模块可设置启用/禁用
- [ ] 拖拽调整执行顺序
- [ ] 设置超时时间
- [ ] 设置重试次数
- [ ] 设置失败后动作
- [ ] 第一环节固定不可删除
- [ ] init-session 不在可选列表
- [ ] 保存为自定义工作流
- [ ] 复制官方预设
- [ ] 所有上传模块包含提示词输入框（可留空）

## J. 重试机制

- [ ] 检测到 "Something went wrong" 后等待配置的秒数
- [ ] 等待后自动重新发送
- [ ] 单个提示词最多重试1次
- [ ] 重试后仍失败则转人工
- [ ] 重试配置可按模块独立设置
- [ ] 重试时不增加使用次数
- [ ] 重试时保留原任务上下文

## K. 素材数据库

- [ ] SQLite 表结构完整（material_id, folder_hash, usage_count 等）
- [ ] 使用次数正确递增
- [ ] 自动选择优先级正确（手动选择 > 0次 > 1次 > 2次 > 3次）
- [ ] 同使用次数按最后使用时间升序
- [ ] 占用锁有效防止重复领取
- [ ] 失败/暂停素材保留原位
