# 0.18.51 文件传输说明交接

## 本次完成

- 扩充 `PAGE_HELP.distributionView`，把文件传输从一句摘要改成可直接照做的使用说明。
- 说明覆盖：产品背景、负责/不负责的边界、首次连接、设备备注与手机身份、手动拖拽发送、自动分发轮询、泛/精准分类、失败恢复、全局去重、操作记录和常见故障。
- 明确库存未知时不把未知当作 0，也不执行自动分发；要求升级接收端并重新连接。

## 未改变

- 没有修改设备发现、库存计算、首次授权、传输协议、重试或成功后去重逻辑。
- 没有触碰登录状态、手机数据、作品文件或当前正在运行的传输任务。

## 使用

1. 刷新工作台或重启桌面端，让静态资源版本 `0.18.51` 生效。
2. 进入“文件传输”，点击右上角 `?`。
3. 按“首次使用”检查接收端、网络、设备身份和库存；需要操作时再按“手动发送”或“自动分发”步骤执行。
