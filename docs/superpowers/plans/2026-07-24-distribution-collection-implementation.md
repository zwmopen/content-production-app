# 作品集与分发功能实施计划

日期：2026-07-24

## 第一阶段（0.2.0，已完成）

1. 建立可测试的作品集实时状态模型。
2. 从小红书、抖音、公众号、归档 Junction 和 CSV 日志计算状态。
3. 重构为左侧工作流导航。
4. 完成作品集筛选、详情和异常提示。
5. 完成手机补货、公众号领取、人工上传确认和设备扫描入口。
6. 接入三种主题并保存本地偏好。
7. 完成自动测试与浏览器回归。

## 第二阶段

1. 素材生产接入现有 ChatGPT 母版窗口的混合模式。
2. 支持指定作品集发送，避免随机预检与真实执行候选不一致。
3. 将每台设备的作品数量、低库存状态结构化回填到设备卡。
4. 为有效归档增加安全恢复计划与确认执行。

## 安全边界

- 工作台不删除源作品集。
- 传输和 Junction 清理只调用共享 Skill。
- 公众号领取不等于发布完成。
- 归档入口异常时不显示可执行恢复按钮。
