# 0.18.50 自动库存记录设备诊断交接

## 本次完成

- 自动库存检查记录会根据 `deviceId` 从当前设备登记/在线快照解析设备身份。
- 展示优先级为电脑端备注，其次手机名称，再其次手机型号/设备标识；可同时显示型号。
- 库存未知事件改为明确结论：设备在线、未上报指定分类库存、自动分发未执行。
- 详情中补充设备备注、手机名称、手机型号、设备标识、自动分发结论、来源说明和处理建议。
- 来源文字改为“自动库存检查（后台轮询）”，避免把内部事件名直接暴露给用户。
- 自动/手动记录图标改为循环/发送符号，并提供 `title`/`aria-label`。
- 自动日志新增设备名称、型号、电脑备注字段，为历史记录和设备快照缺失时提供可恢复身份。

## 不在本次范围

- 没有重启桌面端、清理登录数据、修改设备审批、传输协议或库存计算。
- 浏览器现有页面如果仍显示旧版本，需要刷新工作台或重启桌面端加载 0.18.50 静态资源。

## 运行恢复

1. 刷新/重启工作台。
2. 打开“文件传输 → 操作记录 → 自动分发记录”。
3. 展开“查看详情”，核对设备备注、手机名称、手机型号和设备标识。
4. 看到库存未知时，先升级手机接收端并重新连接，再点击设备刷新；该事件本身不会自动发送。
