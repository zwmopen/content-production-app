# 城市半径 SEO 选题引擎｜产品设计说明

版本：V0.1
日期：2026-08-06
状态：待开发验证

## 1. 产品目标

在现有“团建内容工作台”中增加一个 SEO 选题模块，将城市、周边目的地、企业身份、玩法、素材和搜索数据组合为可执行的内容生产队列。

核心目标：

```text
从“今天发什么”
升级为
“系统告诉我哪些搜索入口尚未覆盖、应该先生产什么内容”
```

模块名称建议：

> 城市半径 SEO 选题引擎

它不是独立内容生成器，而是现有内容生产链的上游计划层。

完整链路：

```text
数据导入/自动规划
→ 关键词与城市关系
→ 机会评分
→ 选题队列
→ 匹配素材和模板
→ 进入内容制作
→ 发布
→ 数据回流
```

---

## 2. 核心业务模型

### 2.1 城市词的双重含义

城市词可能表示：

1. 活动目的地；
2. 用户或公司的出发地。

例如“义乌团建”不等于必须在义乌市区活动，也可能代表“义乌公司寻找周边 1—2 小时可达团建目的地”。

因此系统要建立：

```text
出发城市 → 周边目的地 → 真实车程 → 适用活动
```

### 2.2 关键词矩阵

```text
出发城市
× 目的地
× 企业类型
× 决策角色
× 团队人数
× 活动时长
× 季节
× 玩法
× 预算
× 搜索意图
```

模板示例：

- 义乌公司团建周边去哪玩
- 宜兴制造业 50 人两天一夜团建
- 无锡国企不尴尬团建
- 常州 00 后夏季玩水团建

## 3. 两种数据入口

## 3.1 模式 A：导入聚光/搜索数据

### 支持文件

- CSV
- XLSX

### 导入字段映射

允许用户手动映射：

- 关键词
- 搜索量/热度
- 展现量
- 点击量
- 点击率
- 互动量
- 消耗
- 线索数
- 转化数
- 竞争度
- 时间范围

不同平台字段不一致，导入层必须支持保存映射模板。

### 导入后处理

1. 清洗空值和异常字符；
2. 去重；
3. 同义词合并；
4. 识别城市、区县和小地名；
5. 识别企业类型；
6. 识别 HR、行政等角色；
7. 识别玩法、人数、季节和预算；
8. 聚类成关键词词群；
9. 生成机会评分。

### 第一版边界

第一版不依赖自动抓取小红书数据，优先支持用户合法导入已有数据文件，降低平台规则和接口不稳定风险。

---

## 3.2 模式 B：自动城市半径规划

### 用户输入

- 出发城市
- 时间半径：1/2/3 小时或自定义
- 活动时长：一日/两天一夜
- 团队人数
- 企业类型
- 季节
- 玩法偏好
- 预算范围

### 系统处理

1. 解析出发城市；
2. 获取城市坐标；
3. 查询候选城市和目的地；
4. 计算或读取实际驾车时间；
5. 过滤不合理路线；
6. 匹配本地已有场地、路线和素材；
7. 生成关键词组合；
8. 生成推荐选题；
9. 形成生产队列。

### 距离规则

优先级：

1. 实际驾车时间；
2. 大巴可达性；
3. 一日/两日适配；
4. 直线距离只作为候选预筛。

避免仅用直线距离产生跨江、绕行或不符合真实组织成本的错误关系。

## 7. 机会评分

建议初始公式：

```text
priority =
0.25 × demand
+ 0.20 × commercial_intent
+ 0.20 × content_gap
+ 0.15 × geo_relevance
+ 0.10 × material_fit
+ 0.10 × season_fit
- competition_penalty
```

所有分项标准化为 0—100。

第一版允许权重在设置里修改，并显示“为什么推荐”，不能只输出一个黑箱数字。

解释示例：

```text
推荐原因：
- 关键词有明确企业团建意图
- 当前优质内容较少
- 已有溧阳素材可直接复用
- 宜兴至目的地车程合理
- 夏季玩法适配
```

## 8. 素材与模板匹配

### 内容类型判断

- 团建游戏类 → 游戏模板，图上文字多
- 地点、路线、项目、公司团建类 → 转化模板，图上文字少
- 城市合集与月份推荐 → 合集攻略模板

### 匹配顺序

```text
关键词意图
→ 内容类型
→ 可用素材
→ 素材使用次数
→ 模板类型
→ 具体模板
```

优先选择：

1. 内容匹配；
2. 使用次数较低；
3. 季节正确；
4. 地点真实；
5. 最近没有重复发布。

## 9. 生产系统对接

点击“加入生产队列”后生成任务：

```json
{
  "originCity": "宜兴",
  "destination": "溧阳",
  "keyword": "宜兴周边两天一夜团建",
  "audience": "制造业公司 HR",
  "materialId": "...",
  "templateType": "conversion",
  "templateId": "...",
  "titleHints": ["..."],
  "seoTags": ["宜兴团建", "溧阳团建", "公司团建"]
}
```

内容制作模块读取该任务，生成图片与文案。成品记录需要保留 `topicPlanId`，用于发布后数据回流。

## 12. 开发边界

1. 第一版不自动抓取受限制的平台数据；
2. 不为了地图效果牺牲真实车程；
3. 不自动把所有组合都加入生产队列；
4. 不允许只替换城市名生成伪本地内容；
5. 选题引擎只提供计划，最终内容仍进入现有生产与质检流程；
6. 先跑通数据导入、关系维护和生产队列，再扩展复杂地图与自动路线。

---

## 13. 最终目标

形成一个可积累的团建搜索资产数据库：

```text
城市关系
+ 关键词数据
+ 素材库存
+ 模板库存
+ 发布记录
+ 咨询结果
```

系统持续回答：

- 哪些城市词还没有覆盖？
- 哪些关键词有需求但竞争低？
- 哪个目的地可以服务多个出发城市？
- 哪些素材使用次数最低？
- 应该用游戏模板还是转化模板？
- 哪条内容真正带来了咨询？

最终让内容生产从临时选题，升级为可计算、可复用、可追踪的 SEO 资产建设。
