# 江湖有旅人团建项目｜技能地图与 FDE 交付蓝图

> 这是业务项目地图，不替代软件源码交接文档。
> 软件维护真源仍是本目录源码和 `docs/HANDOFF.md`；本文件负责回答“整个项目有哪些环节、每个环节由什么 Skill / 软件 / 人来完成”。
> 更新时间：2026-08-15

## 1. 先把三个概念分开

### 业务项目

**江湖有旅人团建**是完整业务项目，包含流量、内容、发布、承接、客资、销售和复盘。

### 软件

**团建图文生产工作台**是软件组件，不是整个业务项目。它当前负责把内容生产、作品库、设备分发、在线平台分发、流量转化和设置统一成一个可操作入口。

### 技能

技能是可被 AI 或软件调用的业务能力模块。例如：

- `wechat-teambuilding-conversion`：团建客资统计技能；
- `teambuilding-xhs-workflow`：团建小红书图文生产技能；
- `device-folder-transfer`：设备分发与作品归档技能；
- `business-skill-builder`：业务技能孵化器，不是团建业务本身，而是创建和升级业务技能的元技能。

## 2. 整个项目的业务闭环

```text
流量获取
  ↓
内容选题与素材归档
  ↓
模板迁移与图文生产
  ↓
成品校验、打包、库存
  ↓
抖音 / 小红书 / 公众号 / 其他平台发布
  ↓
评论、私信、群聊承接
  ↓
客资识别、资格判断、联系人解析、去重
  ↓
飞书客资表与销售跟进
  ↓
成交、案例、数据复盘
  ↓
经验进入 FDE 库，反哺下一轮选题、模板、Skill 和软件
```

## 5. 图文工作台六个软件入口对应什么

| 软件入口 | 它维护的东西 | 它不应该拥有的东西 |
|---|---|---|
| 内容制作 | 素材、模板、生产计划、GPT 任务、成品校验 | 不拥有企业客户秘密和平台密码 |
| 作品库 | 作品阶段、平台资格、使用次数、防重复 | 不伪造发布回执 |
| 设备分发 | 设备状态、传输、回执、库存 | 不替代手机端真实接收确认 |
| 在线平台分发 | 平台适配、标题正文准备、人工交接 | 不把“打开页面”冒充“已发布” |
| 流量转化 | 来源、SOP、方案、用户旅程、转化话术 | 不直接代替真实商务承诺 |
| 设置中心 | 路径、运行策略、账号/模型入口、诊断和恢复 | 不展示或存储真实密钥 |

## 6. 提示词、插件和连接器如何管理

### 提示词

提示词不是散落在聊天里的文字，按四类管理：

1. 长期规则：写入 Skill/reference 或项目交接；
2. 模板配方：写入模板仓库和模板注册表；
3. 本批任务要求：写入任务计划和运行记录；
4. 临时试验：写入实验记录，验证后再升级。

### 插件 / 连接器

插件只负责接入能力，不负责成为业务真源。每个连接器都要登记：

- 能读什么；
- 能写什么；
- 授权在哪里；
- 失败会不会产生外部副作用；
- 写入后如何回读；
- 无授权时如何安全停止。

### 本地软件

软件提供稳定状态、任务队列、可观察性和恢复能力；AI 通过 Skill / Core API 调用语义能力，而不是依赖屏幕坐标点击。

## 7. 当前最值得继续抽取的重复劳动

1. **客资证据对账**：群截图、私聊、转发记录、好友资料、飞书行之间的多维匹配；
2. **模板选择**：按人数、地点、季节、活动和平台目标自动找模板；
3. **内容生产计划**：从客资和素材生成一套可执行的页级计划；
4. **生产异常诊断**：额度、登录、页面阶段、图片数量、文案和落盘状态统一解释；
5. **分发安全**：库存、手机、平台阶段、接收回执和防重复统一判断；
6. **转化复盘**：来源 → 咨询 → 入群 → 报价 → 成交的事实链；
7. **企业交付**：需求访谈 → 流程建模 → 原型 → Skill/软件实现 → 试运行 → 培训 → 验收 → 维护。

## 8. 人、Skill、软件的最终边界

```text
人：目标、价值判断、审美、商务承诺、最终发布、低置信度裁决
Skill：稳定规则、字段抽取、分流、去重、提示词编排、报告
软件：状态机、队列、文件/接口操作、权限、可观察性、恢复、审计
连接器：WeFlow、飞书、浏览器、设备和本地 API 的适配
密钥运行态：授权和登录，不进入以上任何公开文档
```

## 11. 技能交付与接管门禁

所有准备交给新的用户或 AI 使用的技能，都要经过“技能包接管与安装门禁”：

```text
发现 → 静态预检 → 安装 → 绑定专属配置 → 重新授权 → 只读试跑 → 验收 → 激活 → 交接
```

门禁会把下一步分给用户、管理员、业务负责人、连接器维护者或开发者；不会把缺授权、身份冲突、表格权限或回读失败静默吞掉。安装、授权、验收和激活分别记录，不能混成一个“已完成”。

- 通用规范：[技能包接管与安装门禁](../../../../项目推进/方法论/FDE-企业交付经验库/技能包接管与安装门禁.md)；
- 交付清单：[技能包交付清单模板](../../../../项目推进/方法论/FDE-企业交付经验库/技能包交付清单模板.md)；
