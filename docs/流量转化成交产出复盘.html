CONTINUOUS CALIBRATION

持续更新与行业校准

由维护技能触发，不后台偷偷改正式资料。

1. 每月读增量

按游标读取新聊天、报价、成交、流失和交付记录，保留来源指针；API 不可用时保留快照并标记待补同步。

2. 对照真实结果

把线索、方案、报价和 won_signal 与合同、定金、执行结果分开比较，避免把意向误算成产出。

3. 校准行业判断

连续观察客群、季节、目的地、预算、供应商、竞争报价和毛利变化；证据足够后再调整判断。

4. 分层写回

新发现先停留在候选层；人工确认且证据充分后，才重建正式 SOP、话术、决策树和本 HTML。
