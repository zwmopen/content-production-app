# 0.16.22 按分类判断手机库存

## 问题

K60 实际只有 8 个精准流量作品，但旧设备接口只上报 15 个总作品。工作台把总数当作精准流量数量，与阈值 10 比较后错误判断为库存充足。

## 修复

- 手机端以可选 `workCounts` 上报总数、精准流量、泛流量和未分类聚合数量。
- 工作台按当前自动分发分类选择对应数值；只有“全部”模式可使用总数。
- 缺少分类数据时安全停止自动判断并记录 `inventory_unknown`。
- 决策指纹包含选中分类库存，在线期间分类数量变化也会重新评估。

## 验证

- 工作台分类选择与设备 JSON 解析测试通过。
- 工作台完整自动回归 444/444 通过（包含新增的 2 项设备状态测试）。
- 共享传送技能 25/25 通过。
- Android 单元测试、Release 构建和 Release Lint 通过；K60 已加载 0.6.17 分类库存协议。
- 工作台 0.16.22 实读到 K60 `total=15 / conversion=8 / traffic=7`，按 `8 < 10` 真实触发并一次成功发送 `作品集_060[转]`，任务到 100%。设备随后离线，尚待重连后回读新的分类数量，才能确认接收后的库存增量。
