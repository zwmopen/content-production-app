# 小红书聚光模板采集按钮

版本：0.19.65
入口：`src/integrations/xhs-template-collector/xhs-inspire-template-collector.user.js`

## 它解决什么问题

在小红书聚光「创意灵感」页面浏览作品时，不需要逐张切换窗口。脚本会在每张作品卡片右下角显示一个小下载按钮；点击后读取卡片本身已公开的标题、笔记 ID、图片槽位、点赞、收藏和评论，并提交给本机 `4327` 工作台。

## 安装与使用

1. 启动图文工作台 `http://127.0.0.1:4327/`。
2. Edge 需要先由用户手动安装并启用 Tampermonkey 或 Violentmonkey；工作台不会偷偷向第三方页面注入脚本，也不会绕过 Edge 扩展安装确认。
3. 在脚本管理器中新建脚本，把 `xhs-inspire-template-collector.user.js` 全文粘贴并启用。
4. 打开 `https://ad.xiaohongshu.com/microapp/creativity/inspire`，卡片右下角会出现 `↓`。
5. 点击一次即可登记并尝试启动本地模板仓库下载；按钮变为 `✓`、`!` 或 `×`，分别表示已入队/已存在、待补真实链接、失败。

脚本不会自动点击卡片、打开笔记、读取浏览器 Cookie，也不会替用户发布内容。若卡片 DOM 已暴露真实的 `/explore/` 详情链接，脚本会一并提交给下载队列；只有拿到笔记 ID、没有真实详情链接时，才会登记为“待补真实小红书链接”。它只请求本机接口：

- `POST http://127.0.0.1:4327/api/template-collector/queue`
- `GET http://127.0.0.1:4327/api/template-collector/ledger`

## 去重与数据位置

- 稳定键：`xhs:<24位笔记ID>`。
- 账本：`D:\AICode\项目推进\模板仓库\采集\聚光作品采集索引.json`。
- 下载素材和 `文案.txt`：仍由现有 `xhs-dl` 与模板仓库维护技能写入原有素材/待分析目录；脚本不创建第二套素材库。
- 重复点击已登记、已下载或已进入待分析的作品不会重复启动下载。只有失败且这次请求带有真实 `xhslink.cn`/小红书链接时才允许重试。

## 重要限制

聚光卡片 DOM 当前提供笔记 ID，但不提供可直接复用的 `xhslink.cn` 短链令牌。脚本会尝试标准 `https://www.xiaohongshu.com/explore/<noteId>` 地址；下载器无法验证完整来源时会停在“待补真实小红书链接”，不会伪造“已下载”。此时把真实公开短链粘贴到技能中心的“模板仓库添加整理”入口后，可沿同一笔记 ID重试并去重。

## 卸载与恢复

在用户脚本管理器中停用或删除本脚本即可；它只移除自己添加的按钮和样式，不删除模板仓库账本、素材或待分析记录。若要恢复本次登记，先备份账本，再由人工确认后处理对应记录；不要直接删除素材目录。

## 常见问题

- **看不到按钮**：确认脚本匹配地址、4327 工作台已启动，并刷新聚光页面；页面结构变化时先查看浏览器控制台错误。
- **按钮显示 `!`**：这是来源证据不足，不是下载成功。聚光卡片只有 noteId 时不会启动空下载任务；补真实公开短链后，服务端会按同一去重键重试。
- **重复点击没有新下载**：这是预期去重行为，可在账本或 `GET /api/template-collector/ledger` 查看状态。
- **卡片滚动后才出现按钮**：页面是动态加载的，脚本用 `MutationObserver` 监听新增卡片。
