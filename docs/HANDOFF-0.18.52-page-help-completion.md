# 0.18.52 全界面使用说明交接

## 本次完成

- 为内容制作、提示词管理、流量转化、聚光运营和自动化工作流增加统一“？”帮助入口。
- 说明统一回答：背景、用途/范围、是什么、怎么用、如何运行、结果标准、限制与排错。
- 继续复用现有系统说明弹窗和滚动容器，不新增平行帮助系统。

## 未改变

- 没有修改 GPT 生产、文件传输、在线发布、流量转化数据读取或聚光数据逻辑。
- 没有触碰登录状态、设备数据、作品文件或正在运行的任务。

## 使用

1. 刷新工作台或重启桌面端，让静态资源版本 `0.18.52` 生效。
2. 在内容制作、提示词、流量转化、聚光运营或工作流页面点击右上角/操作区的 `?`。
3. 按对应页面的“怎么用”和“常见排错”执行；说明只解释真实行为，不代替业务操作。
