稳定版正式确立，此后不再直接在生产目录动代码，维护开发严格遵循双轨物理隔离与基线化发版准则。

## 2. 核心架构与关键能力

### (1) 双浏览器独立实例隔离架构
- **实例 A**：业务端口 `4331` / CDP 调试端口 `9431` / 独立 Profile `instance-A\electron-userdata`（Plus 账号 1）；
- **实例 C**：业务端口 `4333` / CDP 调试端口 `9433` / 独立 Profile `instance-C\electron-userdata`（Plus 账号 3）；
- 两端物理隔离，统一由核心调度脚本驱动，互不串号、互不争抢句柄。

### (2) SPA 独立新会话无硬刷新复用
- 摒弃以往导致白屏与 Cloudflare 拦截的 `page.reload()` 硬刷新模式；
- 采用 SPA 模式轻量点击“新聊天”按钮秒级重置上下文，彻底杜绝长会话污染和大模型风控降级。

### (3) V5.0 遵循原图排版骨架提示词
- **排版铁律**：原图怎么排就怎么改，原图是清秀实拍就保持通透，原图是大字营销就继承大字，绝不千篇一律强套粗黑大字；
- **四宫格强制置换**：四宫格拼图强制打乱站位重排，绝不原地换脸；
- **真实手机质感**：彻底消除 3D 凡士林发光磨皮与假人脸，还原自然光与真实生活噪点。

### (4) 190 张/天 单账号配额安全气囊
- 单账号 3 小时安全阈值：**35 张**；
- 单账号 24 小时绝对安全红线：**190 张**（严格预留 10 张防熔断与防风控检测安全隔离带，坚决杜绝触发官方 200 张熔断与 24 小时死锁）；
- 支持多账号轮换热插拔与 LinkAI 商业中转秒级兜底。

### (5) 飞书画册级对比总表自动化与多模态质检
- 自动写入飞书 A1:O107 总表，原料行与成品行上下比对；
- 成品行整行（A:O）浅天蓝色高亮（`#E8F3FF`）；
- 物理大图 100% 由 `feishu-alt-1` 承载，用户主号 0 存储消耗；
- 接入 `xhs-image-ai-auditor` 质检官，自动回填 N 列（预计分数）与 O 列（诊断备注）。

### (6) 防风控 5~10 分钟随机静默缓冲与 Round-Robin 均衡调度
- **解冻防风控随机隔离**：捕获配额上限后安全休眠，计划任务唤醒后进入 300~600 秒随机静默缓冲，避开整秒整分特征与时钟容差；
- **16 核心目的地轮转调度**：待生产队列采用安吉、千岛湖、莫干山、桐庐、杭州、苏州、上海等 16 个核心城市交替轮转出菜，杜绝单地扎堆，赋能矩阵式多号分发。

### (7) 规范成品目录命名（结构化标签与爬虫降噪）
- 统一输出目录格式为：**`[年月日 时间 网页 CDP-精炼标题]`**（例如：`20260913_194725 网页 CDP-南京秋日露营团建`）；
- 自动清洗爬虫原始脏前缀（`评0-赞2-` 等）与末尾数字噪点，与 API 模式的 `YYYYMMDD Codex API-标题` 形成高度对称的直观标识。

## 3. 多业务拓展蓝图（单开副本与专属技能隔离）

当前生产线优先完全支撑 **团建项目（秋季与冬季大盘）**。
系统已完成通用化解耦，未来天然支持基于本流水线**“单开副本，横向拓展”**：
1. **副本一：个人自媒体项目**（挂载个人 IP 视觉母版、专属文案库与独立 Skill）；
2. **副本二：数码笔记项目**（挂载产品参数对比、测评排版、避坑文案与独立 Skill）；
3. **隔离铁律**：所有新业务副本各自拥有独立的技能包与输入/输出目录，底层复用通用双轨流水线，互不干扰、互不污染。
