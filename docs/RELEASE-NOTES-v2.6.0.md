## 🎯 系统定位与核心解决痛点

`content-production-app` 是江湖有旅人团队的**全自动图文生产与排产中控台**。
它连接本地素材库、双浏览器 CDP 实例、大模型图像生成与多平台自动化分发，彻底解决：
1. **多账号生产隔离**：实例 A (4331/9431/账号1) 与 实例 C (4333/9433/账号3) 物理隔离，SPA 状态无刷新复用，消除串号与风控死锁；
2. **通宵无人值守流水线**：取料 ➔ 模板映射 ➔ 提示词击发 ➔ 4K原图直存 ➔ 质检门禁 ➔ 飞书画册双行对比 ➔ 成品库分发，全自动闭环；
3. **文案元数据防污染**：内置 `caption-file-policy`，智能剔除 `会话追踪.txt`、`质量报告.txt` 等中间调试日志，确保只提取真实发布文案。

## 🚀 v2.6.0 核心更新与工程固化

1. **627 项全量测试 100% 回归通过**：
   - 修复桌面实例启动参数正则匹配；
   - 修复账号隔离策略中的 Canonical 实例与 DEV 实例断言；
   - 修复成品树元数据文件过滤逻辑，确保 `会话追踪.txt` 与 `质量报告.txt` 不被错误标记为可上传文案；
   - 修复多平台分发 UI 标题人性化映射。
2. **构建解压即用便携版（Zero-Dependency Portable EXE）**：
   - 基于 Electron 43.2.0 原生打包，输出免安装单文件执行包；
   - 双击即可拉起本地内容生产中控与双浏览器守护。
3. **多平台文案格式规范化（Copy Format 2/3）**：
   - 支持多平台文案标签自动切分（小红书标题+正文、抖音口播大纲、朋友圈短文案）；
   - 兼容旧版纯文本文件自然排序与去重。
4. **灾备金库双重锚定**：
   - 本地工程与 GitHub 远端代码完全对齐；
   - 完整超大归档包与云端金库（Google Drive + 阿里云盘）SHA256 形成双重灾备。
