# 配置示例

这里放随软件一起分发的脱敏配置模板和字段说明。真实密钥、账号、Cookie、Token、微信 UID、登录态、个人作品和运行日志不得进入本目录。

## 朋友圈配置

`moments-settings.example.json` 是朋友圈技能的可分享配置模板，包含目录、每日定时、每月采集时间、选材规则和人工发表边界。它属于软件包的一部分，但不会覆盖用户电脑上的运行配置。

实际运行时采用两层配置：

1. 软件内置默认值：没有本地配置时使用，保持安全默认，不自动点击微信最终“发表”。
2. 本机运行配置：通常位于 `D:\\AICode\\运行数据\\江湖有旅人\\团建工作台\\app-settings.json`，保存用户自己的路径、账号、UID、定时开关和运行状态，优先于默认值。

分享软件时只带本目录的模板；要迁移个人设置，应在私有配置范围内单独导出和传递本机运行配置，不能把它提交到源码仓库。
