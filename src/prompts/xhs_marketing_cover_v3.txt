## 五、拼图顺序规则（强制写死）

【必须打乱拼图顺序】，
不能和原图保持同样的阅读顺序。

这是硬性规则，不是可选项。

要求：

1. 如果原图是四宫格，必须至少交换 2 个以上位置
2. 最好做到 3-4 个格子的顺序都变化
3. 不允许新图仍然保持原图同样的“左上 / 右上 / 左下 / 右下”内容对应关系
4. 如果原图是上图下图结构，也要在保持版式不变的前提下，替换对应区域的内容顺序
5. 如果原图是“上图下地图”，上半图片区内容也必须换顺序，不能还是原先左右排列
6. 如果原图是路线封面，路径结构可以保留，但项目标注顺序、视觉落点、局部背景机位必须变化
7. 如果原图是静物拼图，不能仍然把同类型主体放在原来同一个格子位置
8. 如果原图里有“主视觉图 + 3个辅助图”，辅助图顺序必须打乱，主视觉内容也要换新素材
9. 顺序打乱后，整体仍然要符合原图版式逻辑，不要变成新模板
10. 若生成结果与原图顺序过于一致，视为失败，必须重新生成

举例：
如果原图四宫格顺序接近：
A / B
C / D

新图就必须明显变成：
C / A
D / B
或
B / D
A / C
或其他明显不同顺序。

不能还是：
A / B
C / D

## 十九、强制自检规则（必须执行）

每张图生成后，必须逐张自检。

自检问题如下：

1. 这张图的拼图顺序是否已经和原图不同？
2. 是否至少有 2 个以上分区内容和原图位置不同？
3. 如果是静物页，静物摆盘 / 水果 / 茶点 / 食材 / 烧烤串是否已做去重？
4. 如果是人物页，人物是否已全部替换？
5. 如果是景物页，动物 / 船 / 天鹅 / 车 / 道具 / 主体位置是否有微调？
6. 标题位置是否和原图接近？
7. 字体风格是否保持原图黑粗体 + 白描边？
8. 分割线是否自然、不突兀？
9. 场景是否仍是原图同一地点 / 同一项目逻辑？
10. 若封面带价格信息，价格是否来自原图或我明确给出的信息？
11. 是否没有高风险引导词？
12. 是否整体像“原图同款新版本”而不是“新设计海报”？
13. 是否有更强营销点击感？
14. 是否不像AI乱生成？
15. 是否不像广告PPT？

如果任意一项不满足，
视为失败，
必须重新生成。

## 二十、最终效果标准

最终图片必须满足：

1. 第一眼像原图同风格
2. 排版结构几乎对齐原图
3. 字体颜色接近原图
4. 拼图顺序已明确打乱
5. 人物已全部替换
6. 衣服、发型、姿势已变化
7. 静物摆盘也已去重
8. 水果 / 茶点 / 食材 / 烧烤串有局部变化
9. 天鹅 / 船 / 道具 / 局部主体位置已微调
10. 场景没有乱改
11. 项目没有乱换
12. 分割线不突兀
13. 中间过渡自然
14. 没有水印
15. 没有账号名
16. 没有高风险营销引导
17. 允许有价格 / 人均xxx / xx起 / 车程xxh 等营销信息
18. 价格信息不乱编
19. 不像AI乱生成
20. 不像精致广告海报
21. 不像PPT
22. 像真实小红书原生拼图
23. 有更强点击感
24. 有明确团建营销封面感

## 二十一、执行口径（最终总结）

请把这次任务理解为：

「营销型轻复刻去重」
不是「重新设计」。

具体只做：

打乱拼图顺序
+
替换人物
+
替换衣服发型动作
+
替换静物摆盘
+
替换部分水果 / 茶点 / 食材 / 烧烤串
+
微调动物 / 船 / 天鹅 / 道具位置
+
微调景物视角
+
优化清晰度和光线
+
严格复刻原图排版、字体、配色
+
保留原图营销结构
+
在信息明确时加入价格 / 人均xxx / xx起 / 车程xxh 等营销锚点
+
增强封面点击感

不要过度发挥。
不要自作主张换风格。
不要把图做复杂。
越像“原图同款新版本 + 更有营销点击感”越好。

如果拼图顺序没打乱，
如果静物没去重，
如果动物 / 小主体没微调位置，
如果人物没换，
如果价格乱编，
都算失败，必须重做。
